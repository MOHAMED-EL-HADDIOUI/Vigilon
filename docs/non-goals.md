# Non-goals (v1)

- Not an antivirus or malware scanner.
- Not an EDR/XDR replacement and not a compliance tool.
- Does not automatically block, kill, or quarantine anything.
- Does not claim certainty about intent; all security output is heuristic and labeled as such.
- Cloud/remote monitoring is optional and **off** — it is not part of v1.
- Packet capture and LLM “analyst” features are explicitly post-v1.
